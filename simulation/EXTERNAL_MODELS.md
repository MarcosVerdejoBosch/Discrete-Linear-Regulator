# External model dependencies

Model libraries are not bundled in this first review snapshot. Their redistribution permissions and portable installation are not yet verified. Obtain the appropriate models from their original suppliers; the existing MIT license does not grant rights to third-party models.

The Windows setup uses `get_irf4905.ps1` to download this file if absent and verifies SHA256 `D6363459B4A5086A3F91CD0C973636CA1A4E38215D85DF5D3463C37AF85849F0`. Original notices are preserved. Python preparation requires this file in the supplied model folder.

Machine-specific absolute include paths in published scenario copies were reduced to library filenames. Place dependencies on the LTspice search path or alongside the scenarios. The local simulations were validated before this packaging change; the latest prepared-folder SIM-09 verification is recorded in ../publication/sim09_portability.json. AutoGenerated/2N7000_PLP and LTC1044 symbols may also require local setup. The annotation IRF4905/model irf7328 mismatch remains documented in the review notes.
